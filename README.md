# 🎧 王陆词汇训练室 | IELTS Vocabulary Trainer

> 雅思还没考出来，背单词网站先写出来了。
>
> 虽然暂时不出租本人，但备考期间还是忍不住造了个轮子。🛞

一个为雅思听力词汇训练做的**免费、非官方**小工具。

目标很简单：从「单词看着眼熟」进化到「听得出、知道意思、还能拼出来」。

🌐 **在线体验：[wanglu-vocabulary.netlify.app](https://wanglu-vocabulary.netlify.app/)**

无需注册，不需要下载 App，打开浏览器就能练习。

## ✨ 功能亮点

| 功能 | 介绍 |
|---|---|
| 👀 看词辨义 | 英文 → 中文四选一，自动朗读，也可以手动重播 |
| 🎧 听音辨义 | 隐藏英文，听英音判断中文意思 |
| ✍️ 听音拼写 | 听发音手动输入英文，自动检查拼写 |
| 🧠 10 秒记忆 | 拼错后提供拼写分块、音形对应或简单词形提示 |
| 🔁 错词复习 | 错词自动进入待复习队列 |
| 📚 教材分类 | Chapter → Test Paper / Section → Page |
| 🔊 英式发音 | 优先使用 English (UK)，支持切换发音人和语速 |
| 💾 学习记录 | 自动保存进度，支持导出错词和备份恢复 |

目前覆盖王陆重点章节 **3 / 4 / 5 / 11**，共整理了 **5,195 条词汇与词组**。

部分 Page 保留图片整理顺序，其余 Page 是方便练习的自定义分页，不完全对应原书页码。

## 🚀 使用指南

1. 打开 [在线网站](https://wanglu-vocabulary.netlify.app/)。
2. 选择 Chapter、Test Paper / Section 和 Page。
3. 先进行「看词辨义」，建立词义反应。
4. 再进行「听音辨义」，练习听音识词。
5. 最后通过「听音拼写」巩固拼写能力。
6. 复习错词，直到能够稳定识别。

**推荐顺序：先认词 → 再听词 → 最后听写。**

毕竟连单词是什么意思都不知道就硬听写，多少有点为难自己了。🥲

## 📱 手机 / iPad 发音说明

网站使用浏览器内置的 Web Speech API（`speechSynthesis`），发音依赖设备系统语音。

**苹果设备建议：**

在「设置 → 辅助功能 → 朗读内容 / 朗读与语音 → 声音」中查找并下载 English (UK) 英式英语语音。

如果设备提供 **Daniel**，可以在网站中选择该发音人。不同系统版本的设置名称可能不同。

**关于自动朗读：**

部分手机和平板浏览器会限制自动播放声音。如果新单词没有自动朗读，可以先手动点击「🔊 读给我听」。

安装英音语音包能够改善可用发音人的选择，但不能保证解除浏览器的自动播放限制。

## 💾 学习记录与隐私

- 学习进度保存在当前浏览器的 `localStorage`。
- 无需注册账号。
- 没有跨设备自动同步功能。
- 支持导出 JSON 进度备份，并在其他设备恢复。
- 支持导出错词 CSV。
- 语音由浏览器调用设备语音合成能力，不需要上传个人录音。

更换设备、清理浏览器数据前，建议提前备份。

## 🛠️ 技术实现

轻量级前端工具，主要使用：

- HTML / CSS / JavaScript
- Web Speech API：语音合成
- LocalStorage：本地学习进度
- JSON / CSV：数据备份及导出
- Responsive Design：桌面及移动端适配

不依赖后端账号服务。

独立 HTML 文件也可以尝试在浏览器中离线运行，语音支持情况取决于设备及浏览器。
